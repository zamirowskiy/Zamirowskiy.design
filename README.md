# Портфолио Романа Замировского

Одностраничный сайт на основе `../zamirovsky`: тот же фирменный стиль (кроме шрифтов),
прелоадер, курсор и анимации. Статика без сборки: сайт открывается двойным кликом
по `index.html` или заливается на любой хостинг как есть.

## Админка

Двойной клик по **`Админка.bat`**: браузер сам откроет `http://127.0.0.1:8777/admin/`.
Пока открыто чёрное окно, админка работает. Закрыли окно — админка выключилась.

Что можно менять:

- **Портфолио.** Добавить, удалить, скрыть кейс. Название, клиент, год, описание,
  разделы, теги, картинки (перетаскиванием, первая — обложка). Порядок кейсов
  меняется перетаскиванием карточек. Есть поиск и фильтр по разделам.
- **Разделы.** Кнопки в верхней строке над работами: названия, порядок, новые разделы.
- **Тексты и кнопки.** Меню, главный экран, бегущая строка, «Обо мне», шаги,
  контакты, подвал, заголовок для поисковиков.
- **Логотип и фото.**
- **Резервные копии.** Перед каждым сохранением прежняя версия откладывается,
  хранятся последние 30. Любую можно вернуть.

Правки сохраняются кнопкой «Сохранить» или Ctrl+S. Пока не сохранили,
сайт их не видит.

Большие картинки админка сама уменьшает до 1600 px. Удалённая из кейса картинка
остаётся в `assets/works/`: так случайное удаление не уничтожает файл.

Нужен только Python (уже установлен), больше ничего ставить не надо.

## Что заливать на хостинг

Всё, **кроме**: `admin/`, `tools/`, `Админка.bat`, `data/backups/`, `README.md`.
Без сервера админка на хостинге всё равно ничего не сохранит, но лишнее лучше
не выкладывать.

Порядок такой: правите в админке у себя → сохраняете → заливаете папку на хостинг.

## Что где

```
index.html             разметка; тексты в ней — запасные (для поисковиков)
data/content.js        ВСЁ СОДЕРЖИМОЕ: тексты, разделы, кейсы. Правит админка
assets/works/          картинки кейсов
assets/brand/          логотип и фото, загруженные через админку
assets/fonts/          Onest, JetBrains Mono
css/  js/              стили и логика сайта
admin/                 админка (страница)
tools/admin.py         админка (сервер, только этот компьютер)
tools/build-images.ps1 старый пакетный способ подготовить картинки из D:\Дизайн
```

## Шрифты

Onest — заголовки и кнопки, JetBrains Mono — наборный текст, надзаголовки,
подписи и теги. Лежат локально, подключены в `css/fonts.css`.

## Прямые ссылки на раздел

`…/#logo`, `…/#identity`, `…/#web`, `…/#print`, `…/#cards`: страница откроется
сразу с нужным разделом. Адрес раздела виден в админке на странице «Разделы».
Удобно отправлять клиентам: «вот мои логотипы».

Поиск на сайте ищет по названию, клиенту, описанию, тегам и разделам.
Если нажать на тег в окне проекта, включится поиск по этому тегу.
